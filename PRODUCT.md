# ChatBureau

Compagnon de bureau Windows pour un public francophone. L'utilisateur personnalise un petit chat animé ou importe un PNG, prévisualise le résultat, puis l'applique à son bureau. L'atelier reste une application Windows native en C# / WinForms, sans dépendances NuGet.

Priorités : stabilité des interactions, simplicité, préservation des préférences et des images, mise à jour dans l'application. Les versions publiques sont distribuées via yh4bb/ChatBureau. Le mode Farces propose une animation visuelle ou un défilement limité dans une fenêtre choisie. Activation explicite pour chaque session, arrêt immédiat disponible, aucun clic ni texte injecté.
