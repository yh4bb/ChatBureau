# Historique

## 1.1.0

- Atelier redessiné dans un style inspiré d’iOS : cartes arrondies, aperçu pastel, navigation segmentée, interrupteurs et curseurs personnalisés.
- Catégorie **Mises à jour** intégrée : recherche, téléchargement vérifié et installation avec redémarrage, sans navigateur.
- Réglage des vérifications automatiques accessible dans la même catégorie.
- Gestion des modifications non enregistrées avant installation.
- Suppression des doublons dans la liste des animations de l’aperçu.
- Navigation clavier pour les listes de choix et curseurs.
- Conservation des réglages et des images PNG existants.

## 1.0.0

- Première version destinée à GitHub, issue du prototype ChatBureau v5.
- Atelier de personnalisation, animations et import de personnages PNG.
- Vérification et installation de mises à jour depuis GitHub Releases.
- Compilation, tests et publication automatiques avec GitHub Actions.
